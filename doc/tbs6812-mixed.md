# 同じBonDriverで地デジ・J.83BとISDB-Sを選ぶ

`config/BonDriver_TBS6812_TS.ini`を使うと、1つのBonDriverでUHF、スカパー光、BS、CS110を選局できる。
ISDB-S3とdantto4kは対象外で、従来の構成を使う。**両入力に地上波・衛星の混合信号が来ている環境が前提。**

ビルドした`BonDriver_BDA.dll`と`TBS6812.dll`を同じフォルダーに置き、BonDriverと同じ名前でINIを置く。
配置後はチャンネルスキャンをやり直す。

## 動作

地上系（ISDB-T / J.83B）と衛星系（ISDB-S）ではカードモードとBDAフィルターが違うため、同じグラフでは切り替えられない。
INIの`RebuildGraphForSystemType=1`により、空間の`DVBSystemTypeNumber`が変わる選局でグラフを作り直す。
ネットワークプロバイダーは、従来の単独設定と同じく系統ごとの専用のものを使う。

モードの扱いは「両入力を選局先の系統にそろえる」方針である。

1. もう一方の入力の`Global\`セマフォ（BonDriver_BDAが使用中に保持するもの）を取得する。
   取れなければ別の受信が使用中である。系統をまたぐ選局は失敗を返し、今の受信は続ける。同じ系統なら通常どおり選局する。
2. モードを読み、両入力が選局先の系統なら書き込まない。
3. 違う場合は自分のグラフを閉じて両入力を確保し、`0x3c`に2バイトを書き込む。カードが再起動する。
4. 読み戻しが一致するまで最大`BoardModeSwitchTimeoutMs`（既定45000 ms）待ち、デバイスを列挙し直してグラフを作る。
5. 失敗した場合は、元の系統のグラフを開き直せれば開き直し、選局の失敗を返す。

確認は`OpenTuner`後の最初の選局と、系統をまたぐ選局で行う。同じ系統内の選局ではカードを再起動しない。

## 制限

- 両入力が地上波なら衛星系を2つ目として開けない。逆も同じ。
- モードは閉じても残る。次に別の系統を開くときにカードが再起動する。
- `BonDriver_BDA`を使わないアプリ（メーカーのツール、coaxdなど）の受信は検出できず、再起動で止めてしまう。
- 複数枚のカードでは、グラフを失った状態からの切替は、列挙順で最初に見つかった入力を対象にする。
- 再構築中の`GetTsStream`はデータを返さない。`WaitTsStream`はタイムアウトを返す。

## 検証

- Release_Static x64ビルドと`tools/test-tbs6812.cmd`。INI振り分け、両入力の空き判定、拒否時に受信を続けること、書き込みの順序を確認する。
- `work/bon-driver-list.exe`でテンプレートを読み、UHF 40件、Opticast 109件、BS 26件、CS110 12件を確認した。

実機（2026-10-31、試験前のモードは入力0=地上、入力1=衛星、`bon-driver-probe`使用）：

| 確認内容 | 結果 |
| --- | --- |
| モード書き込みから読み戻し一致まで | 約0.56秒（全回で同程度） |
| 地上波→BSの`SetChannel` | 約5.8～5.9秒 |
| BS→地上波の`SetChannel` | 約8.8～10.7秒 |
| BS→J.83B（H004）の`SetChannel` | 11.1秒 |
| 地上波→J.83B（カード再起動なし） | 約1.5秒 |
| 取得TS（先頭3 MiBを除く） | 全区間で同期・TEI・連続性エラー0、TSIDは0x7C11、0x7C12、0x4010、0x4030、0x3017で一致 |
| 別プロセスが受信中のBS選局 | 27 msで失敗を返し、モードは変更なし。自分のTSは続き、相手の48秒の受信も最大間隔115 ms、エラー0 |
| 別プロセスが受信中の同系統の選局 | 成功（地上波2系統の同時受信） |

BSはカード再起動の直後でも受信でき、信号レベルは約19 dBだった。

修正前の1回目の試験で、BS→地上波の1回だけ公式ドライバー選局直後のロック確認に失敗した（データは約0.8秒後に流れ始めた）。
混在モードに限り地上系の準備で最大2秒ロックを待つよう変更した。修正なしの6選局でも再現しなかったため、
発生頻度が低く、この修正の効果は確認できていない。修正後の試験では失敗していない。

モードの確認や復元には`tools/tbs6812-board-mode.cpp`を使う（引数なしで読み取り、`write 1 2`で書き込み。両入力が空きの時だけ動く）。

2026-10-31、TVTestでチャンネルスキャンと地上波・光・衛星の切替を行い、問題なく視聴できることをユーザーが確認した。

**未検証:** EDCBでの録画、BonDriver_BDAを経由しないアプリとの競合、長時間録画、異常終了後の復旧。
